# Domain Docs

This is a single-context repository.

Before exploring or changing the synchronization domain, read:

- `docs/glossary.md` for the canonical domain vocabulary.
- Relevant records in `docs/adr/` for accepted architectural decisions.
- `docs/notion-schema.md` for the destination data model.
- Relevant workflow specifications under `specs/`.

Use the glossary terms in issue titles, ticket descriptions, tests, and code.
When a new domain term is needed, update the glossary before using it as a
stable concept.

If a change contradicts an ADR, surface the conflict and update the ADR
deliberately instead of silently overriding it.
